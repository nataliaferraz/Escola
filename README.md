Passo a passo para executar o projeto no computador

1- Instalar o git
2- Obter o link do repositório
- Acesse repositório no GitHub que você deseja clonar
- No canto superior direito da página do repositório, clique no botão "Code"
- Copie a URL do repositório
3- Abrir o terminal (Ou git bash)
4- Executar o comando para clonar o repositório git clone https://github.com/usuario/nome-do-repositorio.git no terminal
 - Substitua https://github.com/usuario/nome-do-repositorio.git pela URL do repositório que você copiou
5- Entrar no diretório do projeto com o comando abaixo
   - cd nome-do-repositorio
Pronto!
